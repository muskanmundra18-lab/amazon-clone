# Amazon Homepage Clone

A front-end recreation of an Amazon-style shopping homepage built using **HTML and CSS**.

## Overview

This project was created to practice translating a real-world website layout into a structured front-end implementation.

## Features

- Amazon-inspired navigation layout
- Header and search section
- Hero section
- Product/category cards
- Footer layout
- Custom image assets
- Responsive-oriented page structure

## Tech Stack

- HTML
- CSS

## Project Structure

```text

├── hero_image.jpg

├── box2_image.jpg

```

## Run Locally

```bash
git clone https://github.com/muskanmundra18-lab/amazon-clone.git
cd amazon-clone
```

Open `index.html` in a browser.

No installation or backend is required.
